KiCad EDA

Open-Source Electronic Design Automation Suite

Source Repository
🔎

Schematic Editor (Eeschema)

Full-featured schematic capture tool for designing electronic circuits with hierarchical sheets, symbol libraries, and netlist generation.

🌡

PCB Layout Editor (Pcbnew)

Interactive PCB layout editor with built-in router, design rule checking, and support for complex multi-layer board designs.

👀

3D Viewer

OpenGL-powered 3D visualization of PCB boards with component models, allowing inspection of the complete board assembly.

📄

Gerber Viewer (Gerbview)

View and verify Gerber RS-274X manufacturing files and Excellon drill files before sending to fabrication.

⚙

PCB Calculator

Engineering calculator for trace widths, via currents, board stackup impedances, and other PCB electrical parameters.

📷

Bitmap2Component

Convert bitmap images into PCB footprints or schematic symbols for logos, artwork, and custom graphical elements.

Building from Source

KiCad is a C++ desktop application requiring CMake, wxWidgets 3.2+, and several system libraries. Below is the typical build procedure on Linux:

Install dependencies (Ubuntu/Debian):

sudo apt install -y cmake ninja-build build-essential \
    libwxgtk3.2-dev libboost-all-dev libcairo2-dev \
    libgl1-mesa-dev libocct-modeling-algorithms-dev \
    python3-dev swig libprotobuf-dev protobuf-compiler \
    libnng-dev libcurl4-openssl-dev libgit2-dev

Configure and build:

mkdir build && cd build
cmake -G Ninja -DCMAKE_BUILD_TYPE=Release ..
ninja -j$(nproc)
sudo cmake --install . --prefix /usr/local

CLI export (headless mode):

kicad-cli pcb export easyedapro \
    --output output.epro \
    input.kicad_pcb
